Pax Connect 0.1.9 Beta，适用于 macOS 26 及以上、Apple Silicon。

- 线路管理显示今日流量、三个时段的余量及排行。浮层打开时自动刷新，标尺按已用比例换色。
- 流量提醒按来源检查用量，上传和下载分别设阈值。
- 线路诊断新增浏览器出口对照、Claude 连通性和多源 IP 查询，页签优先展示异常。
- 网络保护和流量提醒设置修改后自动保存。

退出旧版后将新 App 拖到「应用程序」。既有线路、规则和历史数据保存在本机。旧 MCP 会话需要重连。

安装包采用临时签名，尚未通过 Apple 公证。首次打开若被 macOS 拦截，请参照附件安装说明。内置 sing-box v1.14.3，沿用既有 GeoLite 来源。

附件提供 DMG、SHA256 校验文件、构建 manifest、离线安装说明和完整版本说明。
