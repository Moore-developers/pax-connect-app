# Pax Connect 安装帮助

面向用户的完整说明统一维护在 [安装与首次打开](INSTALL.zh-CN.html)，可用浏览器离线打开。DMG 根目录提供该 HTML 文件，并用窗口背景展示「拖入应用程序 → 从应用程序打开」两步。

安装包仅适用于 macOS 26 及更新版本、Apple Silicon。此候选通道临时签名、未公证；首次安全提示与管理员授权的区别、已有数据、更新和卸载均见上述 HTML。
