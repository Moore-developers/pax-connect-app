Pax Connect 0.1.8 Beta，适用于 macOS 26 及以上、Apple Silicon。

- 新增 Antigravity 本机用量与会话分析。可查看 Gemini 模型参考价、推理强度、最近请求的上下文、可确认轮次与计时数据。
- AI Profile 工作台可以按日期和客户端查看用量、缓存率与配置历史。网络概览新增近十天模型用量和排名。
- 网络概览与流量监控合并同一应用跨线路的流量。连接明细按目标聚合，区分活动与失败，并可创建快捷规则。
- 设置显示本机 SQLite 日志与历史库的占用。修正语言选项显示，双击工作台标题栏可贴满当前屏幕的可用区域或还原。

退出旧版后将新 App 拖到「应用程序」完成更新。线路、规则和历史数据保存在本机。仍在运行的旧 MCP 会话需要断开并重新连接。

安装包采用临时签名，尚未通过 Apple 公证。首次打开若被 macOS 拦截，请参照附件中的安装说明。内置 sing-box v1.14.3，沿用既有 GeoLite 来源。

附件提供 DMG、SHA256 校验文件、构建 manifest、离线安装说明和完整版本说明。
