PAX CONNECT · 安装帮助

安装与首次打开

先拖入应用程序，再从应用程序打开。

macOS 26 及更新版本 Apple Silicon · M 系列

不支持 Intel Mac。无需安装 Go、Xcode 或其他开发工具。

1 · 拖入应用程序

  1. 打开下载的 DMG 磁盘映像。
  2. 把左侧 PaxConnect.app 拖到右侧「应用程序」文件夹。等复制完成。
  3. 推出 DMG。在 Finder 的「应用程序」里打开 Pax Connect。

如果已有旧版，请先回到旧版按 ⌘Q 退出，再替换。不要直接在 DMG 内运行应用。

2 · 首次被 macOS 拦截时

此候选版没有 Apple Developer ID 签名与 Apple 公证。首次打开可能被系统阻止；临时签名用于检查代码完整性，不能证明发布者身份。

  1. 确认应用来自你信任的下载来源，并尝试打开一次。
  2. 打开「系统设置 → 隐私与安全」，查找针对 Pax Connect 的「仍要打开」选项。
  3. 按系统提示确认，再打开应用。

系统版本或设备管理策略可能影响能否放行。如果没有这个入口，或系统提示应用已损坏、包含恶意软件，请保留准确提示并向发布者反馈。不要关闭 Gatekeeper 或全局安全保护。

3 · 配置线路，再开启代理

启动应用会启动当前用户后台。按首次引导导入或添加自己的线路，再开启代理。应用不附送代理服务或线路。

开启代理需要权限时，应用会提示管理员授权以启动网络内核。这与首次打开的系统安全提示是两件事。取消授权后应保持代理关闭。

关闭窗口不会退出应用。停止代理释放 Pax 接管的网络；按 ⌘Q 退出应用及其管理的后台。若另一个 VPN/TUN 工具占用网络，请先在对应工具中关闭，Pax 不代为关闭。

4 · 更新、已有数据与卸载

更新：⌘Q 退出旧版，下载并替换应用。配置和本地记录位于 ~/Library/Application Support/Pax Connect/，替换应用不会主动删除这些数据。不同版本的数据兼容以版本说明为准，不保证可以降级。

为什么新安装后还有旧数据？同一个 macOS 用户下，Pax 会读取上述目录中的已有数据，包括曾使用开发版留下的数据。安装包不包含你的个人数据；在没有旧数据的新账号中才会从空数据开始。

卸载：先 ⌘Q 退出，再删除应用。要彻底清除数据，可另外删除上述目录；其中包含线路凭据和本地记录，删除不可恢复，请自行决定是否备份。

5 · 版本说明、许可与反馈

版本说明和第三方许可位于 DMG 的「说明与许可」文件夹，请返回磁盘映像打开该文件夹。查看应用内「关于应用」可确认实际版本与构建号。

Pax 自身的许可文本位于「说明与许可/Pax 许可」：网络内核及其余部分为 GPL-3.0，macOS App 为 PolyForm Noncommercial 1.0.0（仅限非商业使用），API 为 MIT。源码与问题反馈：github.com/Moore-developers/pax-connect-app。

线路配置、本地网络历史和 AI CLI 用量记录保存在本机。部分功能会访问订阅、测速目标、规则更新源或网站图标来源。

反馈请附 macOS 版本、芯片、Pax 版本与构建号、复现步骤和脱敏截图。不要公开订阅链接、密码、API Key、完整配置或个人访问历史。反馈入口以发布页面为准。

本帮助可离线阅读，不加载外部字体、图片或脚本。下载包校验值 SHA256SUMS.txt 由发布页面另行提供。
