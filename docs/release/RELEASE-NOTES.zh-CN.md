# Pax Connect 0.1.7 Beta

适用于 macOS 26 及以上、Apple Silicon。Beta 安装包采用临时签名，尚未通过 Apple 公证，通过手动下载安装更新。

## 本次更新

- 设置中可即时切换简体中文和 English，也可跟随 macOS。支持导入和导出语言包。部分旧记录保留原文。线路诊断结果可在 App 内读取，预览、复制和导出报告入口已移除。
- 新增内置 Claude 分流包，默认停用。启用后按目的域名匹配，包含 Google 登录、Stripe 和 Persona 等共享域名。
- 对 Pax 接管中明确命中指定线路的连接，线路未载入时拒绝新连接。确认线路故障后，暂停新连接并关闭已归属该线路的连接，恢复后允许应用重连。可确认归属的 DNS 查询也遵守指定线路。Pax 崩溃或 TUN 接管消失时，流量仍可能直连。
- 移除运行日志及流量数据库的容量上限，继续按保留时间清理。简化流量及 AI 用量表头，调整窄窗布局。

## 更新与数据

退出旧版后用新 App 替换。既有线路、规则、历史和 AI 用量保存在本机。从 0.1.2 或更早版本升级仍会转换日志库。转换失败会保留旧记录和备份并报告状态。升级后的数据库不保证支持降级读取。已有 MCP 会话需要重新连接。

## 安装与许可

首次打开可能被 macOS 拦截，具体步骤见随包安装说明。使用 Pax 网络接管前，请先处理其他 VPN 或 TUN 占用。
