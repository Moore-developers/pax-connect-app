# Pax Connect 0.1.1 Beta

macOS 26及以上、Apple Silicon；当前App为中文界面。沿用临时签名、无Apple公证的Beta分发方式，手动下载更新。

## 本次更新

- 模型用量区分官方订阅账号、官方API和第三方中转。保留Profile名称；官方账号无需创建Profile即可读取本机CLI日志。
- 官方账号金额显示「API等值估算」，不当成订阅扣费，不显示倍率或渠道金额。
- 修正切回账号后仍沿用旧中转Profile/倍率的问题；已入库历史保持原状，无法确定来源的请求明确标记。
- 支持识别未显式填写地址的默认官方API配置，已有API Profile之间仍局部更新地址与Key。
- 账号登录说明按使用官方账号、改用API、用量与费用分组精简。

## 更新与数据

升级前退出旧版并备份数据，再用新App替换。新版本将AI用量小时汇总扩展到schema12，保留旧请求、费用与聚合；不承诺降级兼容。发布者备份位于本机~/.pax，不包含在安装包。

官方账号登录和账号/API认证切换仍由CLI完成。Pax不保存登录令牌，不读取网页/手机全账号用量、订阅余额或剩余额度。配置存在不证明登录或运行中的CLI已采用配置。

## 安装、许可与已知限制

首次打开可能被macOS拦截，具体步骤见随包安装说明；本地临时签名通过不等于通过Gatekeeper。使用Pax网络接管前应处理其它VPN/TUN占用。
