# Pax Connect 0.1.2 Beta

macOS 26及以上、Apple Silicon；当前App为中文界面。沿用临时签名、无Apple公证的Beta分发方式，手动下载更新。

## 本次更新

- 修复CF优选列表顶部延迟、IP地区与下载测试受旧扫描限制、完成后没有结果的问题。旧记录可在当前物理网络重新测试，结果即时回填并保存。
- 修复失败扫描的临时空视图遮住后续测试结果；下载前TCP失败也正常显示失败。
- 复用其它网络的有效IP地区缓存时，保留原查询时间并显示到本次记录，避免重复联网或空白。
- 修正运行日志、流量和连接详情中的线路归属，已知线路显示名称，缺失名称保留可追溯身份提示。

## 更新与数据

退出旧版后用新App替换。沿用0.1.1的数据结构，本版不新增数据库迁移；保留线路配置、历史与用量。旧历史的离线修复为独立维护操作，不在升级时自动批量改写。

发布者备份位于本机~/.pax，不包含在安装包。仍为手动下载更新，不承诺降级兼容。

## 安装、许可与已知限制

首次打开可能被macOS拦截，具体步骤见随包安装说明；本地临时签名通过不等于通过Gatekeeper。使用Pax网络接管前应处理其它VPN/TUN占用。

核心及其余部分GPL-3.0，macOS App为PolyForm Noncommercial 1.0.0，API为MIT；许可文本位于DMG「说明与许可/Pax许可」。源码为公开仓库[对应标签v0.1.2](https://github.com/Moore-developers/pax-connect-app/tree/v0.1.2)，最终build和源码提交见manifest。

真实下载、干净机器安装、最低系统、网络授权/睡眠换网和覆盖升级以本版验收记录为准，未验条件如实保留。本版保留原中国IP地址表与更新来源，GeoLite衍生数据的条款取证及发布决定见随源码的分发条件记录。
