# Pax Connect 0.1.9 Beta

适用于 macOS 26 及以上、Apple Silicon。Beta 安装包采用临时签名，尚未通过 Apple 公证，通过手动下载安装更新。

## 本次更新

- 线路管理显示各线路今日上传和下载量。打开用量浮层可查看三个时段的余量、阈值进度和今日流量排行。浮层读取最新采集数据并自动刷新，缺测时按已记录流量计算并标明记录缺口。
- 新增流量提醒。可分别设置上传与下载阈值，按来源检查最近 5 分钟、1 或 2 小时、24 小时的用量。
- 线路诊断新增浏览器出口对照、Claude 连通性和多源 IP 查询。各页签显示重点结果，并提示浏览器出口与线路出口的差异。
- 网络保护与流量提醒的设置在修改后自动保存。

## 更新与数据

退出旧版后，将新 App 放进「应用程序」。既有线路、规则、历史和 AI 用量保存在本机。升级后，已打开的旧 MCP 会话需要重连。可从设置的「MCP 接入」检查入口并连接客户端。

## 安装与许可

首次打开可能被 macOS 拦截，具体步骤见随包安装说明。使用 Pax 网络接管前，请先处理其他 VPN 或 TUN 占用。
