# Pax Connect 0.1.8 Beta

适用于 macOS 26 及以上、Apple Silicon。Beta 安装包采用临时签名，尚未通过 Apple 公证，通过手动下载安装更新。

## 本次更新

- 新增 Antigravity 本机 AI 用量，支持查看 Gemini 模型参考价、会话轮次、推理强度、最近请求的上下文，以及可读到的总耗时和 TPS。Gemini 4 Neon 在 300k 上下文时预警，费用估算按 350k 上限计算。
- AI Profile 工作台新增按日期和客户端筛选的期间用量、累计用量、缓存命中率和客户端配置历史。网络概览新增近十天的模型用量和排名。
- 网络概览调整线路摘要、趋势及流量排行。网络概览与流量监控按应用合并跨线路数据。连接明细按目标聚合，区分活动和失败连接，并可从明细创建规则。
- 设置页新增 SQLite 日志与历史库占用统计。修正语言选项显示；双击工作台标题栏可贴满当前屏幕可用区域或还原。

## 更新与数据

退出旧版后用新 App 替换。既有线路、规则、历史和 AI 用量保存在本机。从 0.1.2 或更早版本升级仍会转换日志库。转换失败会保留旧记录和备份并报告状态。升级后的数据库不保证支持降级读取。仍在运行的旧 MCP 会话需要断开并重新连接。

## 安装与许可

首次打开可能被 macOS 拦截，具体步骤见随包安装说明。使用 Pax 网络接管前，请先处理其他 VPN 或 TUN 占用。
