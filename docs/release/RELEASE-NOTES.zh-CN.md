# Pax Connect 0.1.4 Beta

macOS 26及以上、Apple Silicon；当前App为中文界面。沿用临时签名、无Apple公证的Beta分发方式，手动下载更新。

## 本次更新

- 新增本机MCP入口，AI客户端可查询网络状态、线路、日志、模型用量与会话。按显式授权可管理线路与订阅、网络诊断、API配置、CF优选和设置。
- 设置页增加MCP就绪检查及Codex、Claude Code、DeepSeek Harness客户端接入。新接入默认只读，可选查询与诊断；已有权限保持，冲突不覆盖，原配置先备份。
- MCP操作提供请求身份、任务回查与取消；配置修改保留版本检查，敏感字段脱敏，分页有界。MCP不会自动打开App、启动后台或启用代理。
- 修正网络诊断取消测试的响应时序，精简过时的MCP测试断言。日志库长时使用已由用户确认；进程连续性及全程内存机器取证仍有限制，不宣称完成压力测试。

## 更新与数据

退出旧版后用新App替换。保留线路配置、历史与AI用量。本版不新增数据库结构迁移；从0.1.2或更旧版本升级仍会转换日志库，转换失败会保留旧事实和备份并报告状态。不支持降级读取升级后的库。

打开Pax的「设置 → MCP」检查并接入客户端；入口验证通过只代表初始化和工具发现成功，不代表目标客户端已连接。升级后已有MCP会话需要重新连接。仅在Pax运行时提供业务查询与操作；查询所得域名、日志或会话数据可能由所用AI客户端发送至其服务。

发布者数据备份位于本机~/.pax，不包含在安装包。客户端配置备份保留在用户私有数据目录。
