# Pax Connect 0.1.3 Beta

macOS 26及以上、Apple Silicon；当前App为中文界面。沿用临时签名、无Apple公证的Beta分发方式，手动下载更新。

## 本次更新

- 日志改用列式存储与有界查询，减少大批历史记录读取时的内存占用；日志、流量和详情继续使用真实历史事实。
- 网络诊断补充本机与浏览器的DNS路径、WebRTC公网出口、IPv6与定位风险说明。无法确认的路径保留未知，不把缺失结果当作安全。
- 多源IP资料查询保留原12个来源；超时或缺失来源显示原因，诊断摘要改用墨绿与冷灰配色。
- 新安装默认开启WebRTC公网出口限制；已保存设置保持原值。该限制可能影响通话，不保证隐藏所有IP。
- 设置页简化为网络保护、日志和默认折叠的线路测量，移除未接入的占位项及旧后台服务管理；设置和关于页统一紧凑留白与左右对齐。

## 更新与数据

退出旧版后用新App替换。保留线路配置、历史与AI用量。首次从0.1.2升级会转换日志库；转换期间日志查询可能显示“正在转换”，完成后继续读取。失败保留旧事实和备份，并明确报告状态，不回退到旧的全量内存查询。

本机迁移、查询与数据完整性已有验收；日志库连续至少24小时、跨午夜运行的事后验收尚未完成。本版不承诺该长时条件已通过，不承诺旧版本能够读取升级后的日志库。

发布者数据备份位于本机~/.pax，不包含在安装包。缓存和旧App清理不删除用户配置或历史数据库。

## 安装、许可与已知限制

首次打开可能被macOS拦截，具体步骤见随包安装说明；本地临时签名通过不等于通过Gatekeeper。使用Pax网络接管前应处理其它VPN/TUN占用。
